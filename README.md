# Snake-Game

Java Swing Game

### 📝 Description: 
Snake is a video game genre where you guide a growing line, or snake, across a grid or arena to eat food items while avoiding walls and your own tail


![Behance](https://img.shields.io/badge/Version-V1.0.0-1769ff?style=for-the-badge&logo=&logoColor=white)

Build using [Java Applet libraries](https://docs.oracle.com/javase/7/docs/api/javax/swing/package-summary.html)

### Classes:
* Ball
* GTennis
* HumanHand

### Extends & Implements: 
* Applet
* KeyListener
* Runnable
